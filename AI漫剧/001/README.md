# AI 漫剧第 001 集

## 本集标题

彩虹独角兽向迪莫道歉

## 当前版本

- 镜头数：4 个
- 目标时长：60 秒
- 当前画风：毛毡定格动画
- 当前流程：图片已定稿，下一步先做图生视频动态片段

## 统一制作顺序

1. `01_策划/`：确定本集核心梗和登场精灵。
2. `02_剧本/`：写完整对白和剧情。
3. `03_分镜/`：拆成镜头，确定每个镜头时长。
4. `04_图片/`：生成每个镜头的画面。
5. `05_图生视频/`：把定稿图片生成动态视频片段。
6. `06_配音/`：按镜头生成或录制配音。
7. `07_剪辑/`：合成视频、字幕、配音、音效和 BGM。
8. `08_成片/`：导出最终视频、封面和发布文案。
