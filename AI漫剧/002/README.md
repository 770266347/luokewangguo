# AI 漫剧第 002 集

## 本集暂定标题

巨鼓象只是正常移动

## 核心梗

闪耀大赛（洛克王国 PVP）中，巨鼓象以夸张的“战鼓轮胎”形态登场，连续碾过雪天队、沙暴队、虫队。所有队伍都以为它在开大，最后巨鼓象恢复本体，无辜表示自己只是正常移动。

## 当前准备状态

- 已建立 002 项目目录。
- 已复制本集主要精灵参考图到 `04_图片/references/`。
- 本集出场阵容已定：雪天队 `雪影娃娃、雪巨人、月牙雪熊`；沙暴队 `布克棱岩、棋契陛下、针叶巡林`；虫队 `女王蜂、花衣蝶、铠甲虫`；主角 `巨鼓象`。

## 统一制作顺序

1. `01_策划/`：确定本集核心梗、角色和笑点节奏。
2. `02_剧本/`：写完整对白和剧情。
3. `03_分镜/`：拆镜头，确定镜头时长和画面重点。
4. `04_图片/`：生成 16:9 起始图和角色定稿图。
5. `05_图生视频/`：用 Seedance 2.0 生成动态片段。
6. `06_配音/`：按最终剧本做配音和字幕。
7. `07_剪辑/`：合成视频、字幕、配音、音效和 BGM。
8. `08_成片/`：导出最终视频、封面和发布文案。
