# AI 漫剧第 003 集

## 本集暂定标题

虫队的第四个名额

## 核心梗

洛克王国 PVP 里，虫队一直害怕火神和巨鼓象。食尘短绒找来翼/水属性的锤头鹳后，虫队终于不怕这两个天敌了，但队伍上场名额只有三个。大家商量后决定让食尘短绒自己去替补，最后留下食尘短绒落寞地坐在场边。

## 出场角色

- 虫队：食尘短绒、铠甲虫、陨星虫。
- 压制虫队的对手：火神、巨鼓象。
- 新引进外援：锤头鹳。

## 风格方向

- 整体偏和谐、可爱、愉快。
- 火神和巨鼓象对虫队的压制要夸张但无伤害，用毛绒卷边、弹飞、晕乎乎、变成小绒团等可爱方式表达。
- 结尾要有情绪落点：食尘短绒不是被讨厌，而是为了队伍变强被放到替补席，表情小小落寞。

## 统一制作顺序

1. `01_策划/`：确定核心梗、角色、场景和笑点节奏。
2. `02_剧本/`：写完整剧情、对白和结尾包袱。
3. `03_分镜/`：拆镜头，确定镜头时长、画面重点和声音。
4. `04_图片/`：整理参考图，生成角色定稿图和 16:9 首帧图。
5. `05_图生视频/`：用 Seedance 2.0 生成动态片段。
6. `06_配音/`：按最终剧本做配音、音效和字幕文本。
7. `07_剪辑/`：合成视频、字幕、配音、音效和 BGM。
8. `08_成片/`：导出最终视频、封面和发布文案。

## 本集固定规则

- 角色参考图先来自精灵库或本地精灵图片；第一张确认可用的角色定稿图作为后续主参考。
- 后续同角色镜头不要重新设计角色，只改姿态、表情、镜头角度和场景。
- 首帧图必须是镜头开始状态，不是动作完成后的结果图。
- Seedance 复制区必须自包含：角色外观、动作、声音、台词、负向约束都写在复制区内。
- 禁止生成可读文字、字幕、水印、logo、游戏 UI、角色列表、任务文字、小地图。
- 图生视频提示词统一采用“基础设定 + 氛围与画质 + 分镜内容 + Seedance 复制区”结构。
- 有台词镜头只写轻微说话口型，不要求精确口型同步，避免四足或复杂精灵脸型崩坏。
