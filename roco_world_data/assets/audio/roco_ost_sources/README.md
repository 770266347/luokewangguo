# 洛克王国原声来源记录

本目录用于记录洛克王国 / 洛克王国：世界相关 BGM、主题曲、原声资料的来源状态。

当前没有直接下载第三方搬运、网盘合集、B 站抽音频或未知 MP3 站点文件。原因是这些来源通常只有在线播放或搬运展示，没有明确授权可复制到素材库。

可执行规则：

- 官方或音乐平台页面：记录链接和曲目信息；如平台提供已授权下载，手动下载后可放入 `licensed_audio/`。
- 用户自有授权文件：可放入 `licensed_audio/`，并在 `sources.csv` 标记为 `user_provided_license`。
- B 站合集 / 网盘 / 第三方 MP3：只记录为参考，不下载、不入库成可用素材。

建议目录：

- `licensed_audio/`：只放已确认授权或你自有授权的音频文件。
- `reference_links/`：只放链接清单和备注，不放音频。
