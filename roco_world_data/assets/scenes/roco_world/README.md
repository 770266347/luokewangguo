## 使用建议

- 只作为世界观、场景氛围、建筑风格、色彩和光照参考。
- 正式画面仍按每集分镜重新生成。
- 部分官网宣传图带有 UI、文字或活动标识，生成图时不要直接复制这些内容。
- 生成 AI 漫剧图片时，最终画幅优先使用 16:9。
